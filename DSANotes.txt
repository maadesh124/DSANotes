	-update(increment or decrement) only one pointer in each iteration
	-use continue statements
	-make sure that right pointer always leads left pointer
	
2.Array when upper and lower limits of arr[i] is known(conditions like 1<=arr[i]<=N).works only for Integers
	-you can store 2 numbers in arr[i] one should follow above condition.
		let 'a' and 'b' be two numbers, a<=N
		arr[i]=b*N +a;
		when you need 'b' just perform arr[i]/N, when you need 'a' perform arr[i]%N.
		reference="https://takeuforward.org/data-structure/count-frequency-of-each-element-in-the-array/"

4.When you need a data structure with O(1) insertion, deletion and O(1) search operation use HashMap.
	-Store element to be searched as key and its associated data as value 				in map,now search can be performd in O(1) ,worst case= O(n)
	-example : 2 sum problem -return i,j such that arr[i]+arr[j]==k(given num),
	-brute forsce:iterate through arr for each arr[i] check wheather k-arr[i] exits in arr
	-this takes O(n^2) time complexity. 
	-optimised oproach:Assuming each eleent occurs only once.store all elements of arr in map such that key=arr[i] ,value=i.
	-now perform search in map instead of array,time complexity=O(n) ,(worst case=O(n^2),this is very very rare)
	-reference="https://leetcode.com/problems/two-sum/submissions/1405949079/"

8.No. of Answers with Exactly k=No. of Answers with atleast k -No. of Answers with atleast k+1 
	-Example: No. of substrings with exactly k elements = No. of substrings with atleast k elements-No. of Substring with atleast k+1 elements(refer GFG problem -No. of substring with eactly k elements).
	
9.Extra pointer in Linked Lists 
	-Sometimes an extra pointer can be used with original pointer to find the required node
	-Example 1:middle element of Linked list can be found using slow and fast pointer, when fast pointer reaches end slow pointer is at middle node
	-Example 2:Nth last element:when two pointers with same speed but with initial offset of N can be used to find Nth last Element.fast pointer leads slow pointer by N nodes, when fast pointer is at end,slow is at N th last element
	-Loop problems :slow and fast pointers can be used to solve loop problems like "Length of the loop".When fast pointer leads slow pointer by N nodes then they will meet after N iterations(Speed of slow ptr is 1 Node/iteration,speed of fast is 2 node/iteration).
	
10. Optimal solution -Binary search on Answers
	-Problems whose solution is bounded can be solved using binary search(answer lies in the given range of numbers).
	Example:Find square root of a number in log n:We know that the answer lies in the range 1 to n.Hence binary searching in this range leads to answer	

11. K nested loop : How to create a k loops nested within one another when k is not known at compile time.
	-This can be solved using recursion.Example:To generate all k digit number the function should call itself 10 times within it(Each index takes 10 values from 0 to 9).
	-Example :Generate all binary strings.In this problem each character at index can take two values '1' or '0'.So the function should call itself twice inside it.
	-Solution: brute force-generate all possible binary string of given length and then filter it before adding it to list.
	-Optimal oproach: directly generate only valid binary strings. 	
	
12.BackTracking is used to solve two types of problem "Permutation problem" and "Combination Problem"
	-when each index of answer takes multiple values it is Permutation problem.(requires for loop inside recursive function to iterate between all possible values).For each iteration put a particular value and call recursive function with next index then remove the added element and move to next iteration.ref:https://www.geeksforgeeks.org/write-a-c-program-to-print-all-permutations-of-a-given-string/
	-when each index of answer takes only 2 values(element at index of source is either picked or not picked) it is Cobination problem.recursive function is called only twice within it.For each index first pick the value ,call the recursive function then remove the added element and call the recursive function again.ref:https://takeuforward.org/data-structure/power-set-print-all-the-possible-subsequences-of-the-string/
